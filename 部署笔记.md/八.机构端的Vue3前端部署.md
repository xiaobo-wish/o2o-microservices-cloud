# 八.机构端的Vue3前端部署

[TOC]

浏览器通过 :30889 访问机构端，Nginx 把 /api/ 反向代理到网关（与管理端共用 jzo2o-gateway:11500），网关再按路径路由到各微服务。

区别只有一个端口：管理端占用 NodePort 30888，机构端用 NodePort 30889。

##### 3.Config Map配置

```bash
cat > /data/jzo2o-single/15-frontend-institution/frontend-institution.yaml <<'EOF'
apiVersion: v1
kind: ConfigMap
metadata:
  name: institution-nginx-config
  namespace: jzo2o
data:
  default.conf: |
    server {
        listen 80;
        server_name _;
        client_max_body_size 30m;

        root /usr/share/nginx/html;
        index index.html index.htm;

        location / {
            try_files $uri $uri/ /index.html;
        }

        location /api/ {
            proxy_pass http://jzo2o-gateway:11500/;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }
    }
EOF
```

注意反代时去掉了 /api 前缀（proxy_pass http://jzo2o-gateway:11500/;），因为网关的路由路径本身是 /foundations/**、/customer/** 这种形式，不带 /api。也就是带后面那个斜杠可以替换/api

##### 4.Deployment部署

```bash
cat >> /data/jzo2o-single/15-frontend-institution/frontend-institution.yaml <<'EOF'
apiVersion: apps/v1
kind: Deployment
metadata:
  name: project-xzb-pc-vue3-java
  namespace: jzo2o
spec:
  replicas: 1
  selector:
    matchLabels:
      app: project-xzb-pc-vue3-java
  template:
    metadata:
      labels:
        app: project-xzb-pc-vue3-java
    spec:
      containers:
        - name: nginx
          image: docker.io/jzo2o/project-xzb-pc-vue3-java:1.0.0
          imagePullPolicy: IfNotPresent
          resources:
            requests:
              cpu: 10m
              memory: 32Mi
            limits:
              cpu: 100m
              memory: 128Mi
          ports:
            - name: http
              containerPort: 80
          volumeMounts:
            - name: institution-nginx-config
              mountPath: /etc/nginx/conf.d/default.conf
              subPath: default.conf
              readOnly: true
      volumes:
        - name: institution-nginx-config
          configMap:
            name: institution-nginx-config
EOF
```

##### 5.Service部署

```bash
cat >> /data/jzo2o-single/15-frontend-institution/frontend-institution.yaml <<'EOF'
apiVersion: v1
kind: Service
metadata:
  name: project-xzb-pc-vue3-java
  namespace: jzo2o
spec:
  type: NodePort
  selector:
    app: project-xzb-pc-vue3-java
  ports:
    - name: http
      port: 80
      targetPort: 80
      nodePort: 30889
EOF
kubectl apply -f /data/jzo2o-single/15-frontend-institution/frontend-institution.yaml
```

管理端已占 30888，机构端用 30889。

网关占位 Service jzo2o-gateway已创建（Nginx 启动时解析上游域名

Service 不存在会 [emerg] host not found），这里直接复用。
