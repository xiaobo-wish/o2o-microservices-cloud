###  1.jzo2o-orders-manager 订单管理

**部署思路**：orders-manager 是订单管理服务，运营端"订单管理"菜单背后就是它——订单列表 / 详情 / 派单操作都由它承接。端口 11504，上下文路径 /orders-manager。

数据库走 **ShardingSphere 订单分片库**（jzo2o-orders 库分片）。单节点交付版为单库退化形态：只建 jzo2o-orders 一个库，分片规则退化为单库路由，业务无感知。

订单域 4 个服务结构完全一致。

1.创建yaml文件目录

```bash
[root@master01 ~]# mkdir -p /data/jzo2o-single/12-microservice/jzo2o-orders-manager && cd $_
```

2.Deployment 无状态应用部署

```bash
cat > /data/jzo2o-single/12-microservice/jzo2o-orders-manager/orders-manager.yaml <<'EOF'
apiVersion: apps/v1
kind: Deployment
metadata:
  name: jzo2o-orders-manager
  namespace: jzo2o
spec:
  replicas: 1
  selector:
    matchLabels:
      app: jzo2o-orders-manager
  template:
    metadata:
      labels:
        app: jzo2o-orders-manager
    spec:
      containers:
        - name: jzo2o-orders-manager
          image: jzo2o/jzo2o-orders-manager:1.0.0
          imagePullPolicy: IfNotPresent
          ports:
            - containerPort: 11504
          env:
            - name: NACOS_USERNAME
              value: nacos
            - name: NACOS_PASSWORD
              value: nacos
            - name: NACOS_ADDR
              value: nacos:8848
            - name: NACOS_NAMESPACE
              value: "75a593f5-33e6-4c65-b2a0-18c403d20f63"
            - name: JAVA_OPTS
              value: "-Dspring.profiles.active=prod -Xms128m -Xmx256m"
EOF
```

3.Service部署

```bash
cat >> /data/jzo2o-single/12-microservice/jzo2o-orders-manager/orders-manager.yaml <<'EOF'
apiVersion: v1
kind: Service
metadata:
  name: jzo2o-orders-manager
  namespace: jzo2o
spec:
  type: ClusterIP
  selector:
    app: jzo2o-orders-manager
  ports:
    - name: http
      port: 11504
      targetPort: 11504
EOF
kubectl apply -f /data/jzo2o-single/12-microservice/jzo2o-orders-manager/orders-manager.yaml
```


**订单主链路常见问题排查**：

订单主链路常见问题排查：

1. 现象：订单管理接口 502 / 503；原因：网关未注册或路由失败；解决：先确认网关可访问、订单域服务都注册成功。
2. 现象：订单列表没数据；原因：分片库 jzo2o-orders 未导入 / ShardingSphere 配置错；解决：确认业务库已导入并抽查数据。
3. 现象：下单 / 派单接口报错；原因：Seata / RabbitMQ / Redis 未就绪；解决：kubectl logs 看对应服务日志，确认中间件先就绪。
4. 现象：支付接口失败；原因：jzo2o-trade 库未补建；解决：补建 trade 库后重启 trade。
